# docs/history

Features as designed at the time. These are the specs and plans written before and during the first build of Switchboard (2026-10-11 to 2026-10-15). They are frozen records: they may name packages, files, endpoints and Make targets that no longer exist, and each carries a banner saying so.

- `superpowers/specs/`: 13 design documents.
- `superpowers/plans/`: 22 implementation plans.

Path rule: a path `docs/superpowers/{plans,specs}/X` written inside these files now lives at `docs/history/superpowers/{plans,specs}/X`, unless `X` is a remediation record, which lives at `docs/superpowers/remediation/{plans,specs}/X` (see [docs/superpowers](../superpowers/README.md)). File names never changed.

Do not edit these files; write a new document instead. For current behaviour read [the parity matrix](../pipecat-parity-matrix.md) and the other documents linked from the [README](../../README.md).
