> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the three-mode MCP Servers page (list table, create form, detail) with the Switchboard **MCP tools** screen (canvas board 16): servers on the left with a status line each, the selected server on the right (endpoint, token variable, the flows that use it, a tools table), a **schema-change review** that lets an operator accept a changed tool schema for the flows that pinned the old one, and dialogs for connecting and deleting a server. ## What the server really does (verified in `server/mcp/*.go`, `server/agent/service.go`, `server/api_routes.go`)

- **Server states** (`validation_state`): `not_validated`, `healthy`, `authentication_failed`, `connection_failed`, `discovery_failed`, `tool_schema_invalid`, `disabled`. The current page tests for `valid`, `connected`, `invalid`, `schema_invalid` and `unreachable`, none of which the server ever sends: a healthy server shows a neutral "healthy" badge and a failed one shows neutral too. **Existing bug; this plan fixes it.**
- `GET /mcp-servers` returns servers with `enabled`, `pending_deletion`, `auth_env`, `auth_env_set`, `last_connected_at`, `last_discovered_at`, `latest_discovery_id` and **no tool count**; `GET /mcp-servers/{id}` adds `discovery: { id, discovery_hash, created_at, tools: [{ remote_name, description, input_schema, schema_hash }] }`.
- Actions: `POST …/validate` (re-discover; failures show in the returned view, not as an HTTP error), `POST …/enable` (409 while deletion is pending), `POST …/disable`, `DELETE …` (409 `mcp_server_in_use` with details while flows or live calls reference it), `POST …/detach-delete` with `{ "confirm": true }` (204-like `deleted`, or 202 `pending` while calls drain), `POST …/tools/{tool}/test`. There is **no endpoint to edit a server** after creating it.
- A flow version pins tools as `{ mcp_server_id, remote_name, schema_hash, required }`. A flow's `readiness.tool_dependencies[]` reports each one's `state`: `ready`, `schema_drift` (the server's current hash differs from the pinned one), `tool_missing`, `server_unavailable`, `server_disabled`, with `selected_schema_hash` and `current_schema_hash`. A **required** tool in a state other than `ready` makes the flow `needs_tool_review` (drift or missing) or `tool_dependency_unavailable`; **only `ready` and `ready_with_tool_warning` flows can take calls** (`server/api_routes.go` `callable`). An optional tool only gives `ready_with_tool_warning`. So the canvas copy "flows pinned to the old hash keep working" is **false** for required tools; this plan says what really happens.
- `PUT /agents/{id}/mcp-tools` with `{ tools: [ToolSelection…] }` replaces a flow's tool selection and publishes a new version with the same config (`SetMCPTools`). That is how a changed schema is accepted: the same list with the changed tool's `schema_hash` set to `current_schema_hash`.
- The server stores each pinned schema by hash internally but has **no endpoint to read an old schema**, so a diff (canvas's red/green block) cannot be built: the panel shows the current schema and the two hashes.
- Tokens come only from `MCP_TOKEN_*` environment variables; the API reports only whether the variable is set (`auth_env_set`), never a value.

## Review Focus

1. **Every server state has the right words and tone.** A healthy server must read Connected (ok), every failure state reads as a failure (bad) with its own words, disabled and not-yet-checked are neutral, and a state the UI has never heard of is shown as it is, never as "connected". Pinned in Tasks 1 and 6.
2. **Accepting a changed schema is exact.** It must send the flow's full tool list with only the changed tool's hash replaced and every other tool and `required` flag untouched; never send when the current hash is unknown; show the server's refusal in the dialog; and say truthfully that required flows are blocked until then. Pinned in Tasks 1 and 4.
3. **Deleting is two deliberate steps.** Delete asks first; a 409 `mcp_server_in_use` offers detach-and-delete only after naming the flows affected; nothing is deleted on Escape or Cancel; a 202 pending result shows "Being removed". Pinned in Tasks 5 and 6.
4. **A failing or capped flow list.** Usage counts read "—" (or "at least N"), the panel says drift cannot be checked, and no flow is claimed unused. Pinned in Task 6.
5. **Unknown server, empty list, many servers.** `/mcp-servers/nope` says "That MCP server was not found." with a way back; no servers shows how to connect one; a failing detail request for one server does not hide the list. Pinned in Task 6.

```ts
import { ApiError, type AgentDTO, type MCPServerDTO, type ToolDependencyDTO, type ToolSelection } from "../../api/client";

export type Tone = "ok" | "bad" | "idle";

/** The server's own words for its state, in ours. Only `healthy` is Connected; an unknown state is shown as it is. */
export function serverStatus(s: MCPServerDTO): { tone: Tone; label: string } {
  if (s.pending_deletion) return { tone: "idle", label: "Being removed" };
  if (!s.enabled || s.validation_state === "disabled") return { tone: "idle", label: "Disabled" };
  switch (s.validation_state) {
    case "healthy":
      return { tone: "ok", label: "Connected" };
    case "not_validated":
      return { tone: "idle", label: "Not checked yet" };
    case "authentication_failed":
      return { tone: "bad", label: "Authentication failed" };
    case "connection_failed":
      return { tone: "bad", label: "Unreachable" };
    case "discovery_failed":
      return { tone: "bad", label: "Could not list tools" };
    case "tool_schema_invalid":
      return { tone: "bad", label: "A tool schema is invalid" };
    default:
      return { tone: "idle", label: s.validation_state };
  }
}

/** "4 min ago": the largest sensible unit; "" without a time. `now` is ms since the epoch. */
export function ago(iso: string | null | undefined, now: number): string {
  if (!iso) return "";
  const seconds = (now - Date.parse(iso)) / 1000;
  if (seconds < 60) return "just now";
  if (seconds < 3600) return `${Math.floor(seconds / 60)} min ago`;
  if (seconds < 86400) return `${Math.floor(seconds / 3600)} h ago`;
  return `${Math.floor(seconds / 86400)} d ago`;
}

const live = (flows: AgentDTO[]) => flows.filter((f) => !f.archived);

export function flowsUsingServer(flows: AgentDTO[], serverId: string): AgentDTO[] {
  return live(flows).filter((f) => (f.current_version?.mcp_tools ?? []).some((t) => t.mcp_server_id === serverId));
}

export function flowsUsingTool(flows: AgentDTO[], serverId: string, remoteName: string): AgentDTO[] {
  return live(flows).filter((f) => (f.current_version?.mcp_tools ?? []).some((t) => t.mcp_server_id === serverId && t.remote_name === remoteName));
}

export type Drift = { flow: AgentDTO; dep: ToolDependencyDTO; kind: "changed" | "missing" };

/** Pinned tools of this server whose schema changed, or that the server no longer offers. */
export function drifts(flows: AgentDTO[], serverId: string): Drift[] {
  return live(flows).flatMap((flow) =>
    (flow.readiness.tool_dependencies ?? [])
      .filter((dep) => dep.mcp_server_id === serverId && (dep.state === "schema_drift" || dep.state === "tool_missing"))
      .map((dep): Drift => ({ flow, dep, kind: dep.state === "schema_drift" ? "changed" : "missing" })),
  );
}

/** The flow's tool list with one tool re-pinned to the schema the server offers now. `null` when that cannot be done. */
export function acceptedSelection(flow: AgentDTO, dep: ToolDependencyDTO): ToolSelection[] | null {
  const current = dep.current_schema_hash;
  const tools = flow.current_version?.mcp_tools ?? [];
  const pinned = tools.some((t) => t.mcp_server_id === dep.mcp_server_id && t.remote_name === dep.remote_name);
  if (!current || !pinned) return null;
  return tools.map((t) => (t.mcp_server_id === dep.mcp_server_id && t.remote_name === dep.remote_name ? { ...t, schema_hash: current } : t));
}

export function formatApiError(err: unknown, fallback: string): string {
  if (err instanceof ApiError) return err.requestId ? `${err.message} (Request ID: ${err.requestId})` : err.message;
  if (err instanceof Error) return err.message;
  return fallback;
}
```

```tsx
import { useId, useState } from "react";
import type { ApiClient } from "../../api/client";
import { Status } from "../../components/primitives";
import { formatApiError } from "./mcpStats";

const MAX_ARGUMENT_BYTES = 65_536;

type Run = { executionId: string; status: string; durationMs: number; result: unknown };

/** Runs one tool once, outside a conversation, with arguments typed here. Nothing typed is kept. */
export function ToolTestConsole({ client, serverId, tool }: { client: ApiClient; serverId: string; tool: string }) {
  const id = useId();
  const [text, setText] = useState("{}");
  const [run, setRun] = useState<Run | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [running, setRunning] = useState(false);

  async function execute() {
    setError(null);
    setRun(null);
    let parsed: unknown;
    try {
      parsed = JSON.parse(text || "{}");
    } catch {
      setError("Arguments must be valid JSON");
      return;
    }
    if (typeof parsed !== "object" || parsed === null || Array.isArray(parsed)) {
      setError("Arguments must be a valid JSON object");
      return;
    }
    if (new TextEncoder().encode(text).length > MAX_ARGUMENT_BYTES) {
      setError("Arguments exceed the 64 KiB execution limit");
      return;
    }
    setRunning(true);
    try {
      const res = await client.testMCPTool(serverId, tool, parsed as Record<string, unknown>);
      setRun({ executionId: res.execution_id, status: res.status, durationMs: res.duration_ms, result: res.result });
    } catch (err) {
      setError(formatApiError(err, "Tool execution failed"));
    } finally {
      setRunning(false);
    }
  }

  return (
    <section aria-label={`Try ${tool}`} className="tool-console">
      <p className="subtext">Runs this tool once, outside a conversation, with the arguments below.</p>
      <label htmlFor={id}>JSON arguments (max 64 KiB)</label>
      <textarea id={id} rows={4} value={text} onChange={(e) => setText(e.target.value)} placeholder='{ "param": "value" }' />
      <div>
        <button type="button" className="action-button-small" disabled={running} onClick={() => void execute()}>
          {running ? "Running…" : "Run tool"}
        </button>
      </div>
      {error && (
        <p role="alert" className="tool-console__error">
          {error}
        </p>
      )}
      {run && (
        <div>
          <p className="tool-console__meta">
            <Status tone={run.status === "completed" || run.status === "success" ? "good" : "bad"}>{run.status}</Status>

          </p>
          <pre className="tool-console__result">
            <code>{JSON.stringify(run.result, null, 2)}</code>
          </pre>
        </div>
      )}
    </section>
  );
```

```tsx
import { useId, useState } from "react";
import { Link } from "react-router";
import { useMutation, useQueryClient } from "@tanstack/react-query";
import type { ApiClient } from "../../api/client";
import { Modal } from "../../components/Modal";
import { acceptedSelection, formatApiError, type Drift } from "./mcpStats";

const short = (hash: string | undefined) => (hash ?? "").slice(0, 8);

/** A tool whose input schema changed: what it means for each flow that pinned the old one, and a way to accept the new one. */
export function DriftPanel({ client, tool, schema, items }: { client: ApiClient; tool: string; schema: unknown; items: Drift[] }) {
  const titleId = useId();
  const queryClient = useQueryClient();
  const [accepting, setAccepting] = useState<Drift | null>(null);
  const [error, setError] = useState<string | null>(null);

  const accept = useMutation({
    mutationFn: (d: Drift) => {
      const selection = acceptedSelection(d.flow, d.dep);
      if (!selection) throw new Error("The server's current schema is unknown, so there is nothing to accept.");
      return client.setAgentMCPTools(d.flow.id, selection);
    },
    onSuccess: () => {
      setAccepting(null);
      setError(null);
      void queryClient.invalidateQueries({ queryKey: ["agents"] });
    },
    onError: (err) => setError(formatApiError(err, "Could not publish the new version")),
  });

  return (
    <section aria-labelledby={titleId} className="drift-panel">
      <h3 id={titleId}>{tool} changed its input schema</h3>
      <p>Flows that require it need your review before they take calls again. Flows that use it optionally keep working without it.</p>
      <ul className="drift-flows">
        {items.map((d) => (
          <li key={d.flow.id}>
            <Link to={`/flows/${encodeURIComponent(d.flow.id)}`}>{d.flow.name}</Link>
            <span className="subtext">{d.dep.required ? "requires it" : "uses it optionally"}</span>
            <code>
              {short(d.dep.selected_schema_hash)} → {short(d.dep.current_schema_hash)}
            </code>
            {d.dep.current_schema_hash && (
              <button
                type="button"
                className="action-button-small"
                aria-label={`Accept new schema for ${d.flow.name}`}
                onClick={() => {
                  setError(null);
                  setAccepting(d);
                }}
              >
                Accept new schema
              </button>
            )}
          </li>
        ))}
      </ul>
      <p className="subtext">The server now offers this input schema:</p>
      <pre className="drift-schema">
        <code>{JSON.stringify(schema, null, 2)}</code>
      </pre>

      {accepting && (
        <Modal title={`Accept the new schema for ${accepting.flow.name}?`} onCancel={() => setAccepting(null)}>
          <p>
            This publishes a new version of {accepting.flow.name} that pins {tool} to the schema the server offers now. Calls in progress finish on the version they started on.
          </p>
          {error && (
            <p role="alert" className="tool-console__error">
              {error}
            </p>
          )}
          <div className="dialog__actions">
            <button type="button" className="action-button-small" onClick={() => setAccepting(null)}>
              Cancel
            </button>
            <button type="button" className="action-button" disabled={accept.isPending} onClick={() => accept.mutate(accepting)}>
              {accept.isPending ? "Publishing…" : "Publish new version"}
            </button>
          </div>
        </Modal>
      )}
    </section>
  );
}

/** Pinned tools the server no longer offers. Nothing to accept: the flows need a different tool. */
export function MissingTools({ items }: { items: Drift[] }) {
  const names = [...new Set(items.map((d) => d.dep.remote_name))];
  return (
    <>
      {names.map((name) => (
        <section key={name} className="drift-panel" aria-label={`${name} is no longer offered`}>
          <h3>{name} is no longer offered by this server</h3>
          <p>Flows that require it need your review before they take calls again. Change the step that uses it, then publish.</p>
          <ul className="drift-flows">
            {items
              .filter((d) => d.dep.remote_name === name)
              .map((d) => (
                <li key={d.flow.id}>
                  <Link to={`/flows/${encodeURIComponent(d.flow.id)}`}>{d.flow.name}</Link>
                  <span className="subtext">{d.dep.required ? "requires it" : "uses it optionally"}</span>
                </li>
              ))}
          </ul>
        </section>
      ))}
    </>
  );
}
```

```tsx
import { useId, useState, type FormEvent } from "react";
import type { CreateMCPServerInput } from "../../api/client";
import { Modal } from "../../components/Modal";

// Mirrors the server: only MCP_TOKEN_* variables can be named, so a management key cannot point a server at an unrelated secret.
const AUTH_ENV_PREFIX = "MCP_TOKEN_";
const AUTH_ENV_PATTERN = /^MCP_TOKEN_[A-Z0-9_]{1,48}$/;

export type ConnectServerDialogProps = {
  pending: boolean;
  error: string | null;
  onSubmit: (input: CreateMCPServerInput) => void;
  onCancel: () => void;
};

/** Connect a remote MCP server by endpoint. Only the name of the token variable is entered, never a token. */
export function ConnectServerDialog({ pending, error, onSubmit, onCancel }: ConnectServerDialogProps) {
  const uid = useId();
  const [name, setName] = useState("");
  const [endpoint, setEndpoint] = useState("");
  const [description, setDescription] = useState("");
  const [authEnv, setAuthEnv] = useState("");
  const [enabled, setEnabled] = useState(true);
  const [problem, setProblem] = useState<string | null>(null);

  function submit(e: FormEvent) {
    e.preventDefault();
    if (!name.trim()) return setProblem("Server name is required");
    if (!endpoint.trim()) return setProblem("Endpoint URL is required");
    if (authEnv.trim() && !AUTH_ENV_PATTERN.test(authEnv.trim())) {
      return setProblem(`Token variable must match ${AUTH_ENV_PREFIX} followed by A-Z, 0-9 or _ (max 48).`);
    }
    setProblem(null);
    onSubmit({
      name: name.trim(),
      description: description.trim() || undefined,
      endpoint: endpoint.trim(),
      transport: "streamable-http",
      auth_env: authEnv.trim() || undefined,
      enabled,
    });
  }

  const shown = problem ?? error;
  return (
    <Modal title="Connect server" onCancel={onCancel}>
      <form onSubmit={submit} className="dialog__form" noValidate>
        {shown && (
          <p role="alert" className="tool-console__error">
            {shown}
          </p>
        )}
        <label className="form-field" htmlFor={`${uid}-name`}>
          <span>Name</span>
          <input id={`${uid}-name`} type="text" value={name} autoComplete="off" onChange={(e) => setName(e.target.value)} />
        </label>
        <label className="form-field" htmlFor={`${uid}-endpoint`}>
          <span>Endpoint URL</span>
          <input id={`${uid}-endpoint`} type="url" value={endpoint} placeholder="https://mcp.example.com/rpc" autoComplete="off" onChange={(e) => setEndpoint(e.target.value)} />
        </label>
        <label className="form-field" htmlFor={`${uid}-desc`}>
          <span>Description (optional)</span>

          <label htmlFor={`${uid}-auth`}>Token variable (optional)</label>

          <small>
            The name of a server environment variable starting with <code>{AUTH_ENV_PREFIX}</code>. Its value is sent as the bearer token to this server only. Public hosts only.
          </small>
        </div>
        <label className="check-row" htmlFor={`${uid}-enabled`}>

          <button type="submit" className="action-button" disabled={pending}>
```

```tsx
import { Link } from "react-router";
import type { AgentDTO } from "../../api/client";
import { Modal } from "../../components/Modal";

export type DeleteServerDialogProps = {
  name: string;
  /** The flows that pin this server's tools; `undefined` when the flow list could not be loaded. */
  flows: AgentDTO[] | undefined;
  /** The server refused a plain delete because flows or calls in progress use it. */
  inUse: boolean;
  pending: boolean;
  error: string | null;
  onDelete: () => void;
  onDetach: () => void;
  onCancel: () => void;
};

/** Delete asks first. When the server says the server is in use, detaching is a second, explicit step that names what it affects. */
export function DeleteServerDialog({ name, flows, inUse, pending, error, onDelete, onDetach, onCancel }: DeleteServerDialogProps) {
  return (
    <Modal title={inUse ? `${name} is still in use` : `Delete ${name}?`} onCancel={onCancel}>
      {inUse ? (
        <>
          <p>
            Flows or calls in progress still use this server's tools. Detaching removes its tools from the flows that use them; those flows need review before they take calls again. Calls in progress finish first.
          </p>
          {flows === undefined ? (
            <p className="subtext">Which flows use it could not be loaded.</p>
          ) : flows.length > 0 ? (
            <ul className="drift-flows">
              {flows.map((f) => (
                <li key={f.id}>
                  <Link to={`/flows/${encodeURIComponent(f.id)}`}>{f.name}</Link>
                </li>
              ))}
            </ul>
          ) : null}
        </>
      ) : (
        <p>This removes the server and its tool list. It does not touch the remote server.</p>
      )}
      {error && (
        <p role="alert" className="tool-console__error">
          {error}
        </p>
      )}
      <div className="dialog__actions">
        <button type="button" className="action-button-small" onClick={onCancel}>
          Keep server
        </button>
        {inUse ? (
          <button type="button" className="action-button-small action-button-danger" disabled={pending} onClick={onDetach}>
            {pending ? "Detaching…" : "Detach and delete"}
          </button>
        ) : (
          <button type="button" className="action-button-small action-button-danger" disabled={pending} onClick={onDelete}>
            {pending ? "Deleting…" : "Delete server"}
          </button>
        )}
      </div>
    </Modal>
  );
}
```

```tsx
      {servers.map((s) => {

        const n = changed[s.id] ?? 0;
```

```tsx
import { useState } from "react";
import { Link, useNavigate, useParams } from "react-router";
import { useMutation, useQueries, useQuery, useQueryClient } from "@tanstack/react-query";
import type { ApiClient, ApiError, CreateMCPServerInput } from "../../api/client";
import { EmptyState, ErrorState, LoadingState } from "../../components/primitives";
import { ConnectServerDialog } from "./ConnectServerDialog";
import { ServerDetail } from "./ServerDetail";
import { ServerList } from "./ServerList";
import { drifts, formatApiError } from "./mcpStats";

export type MCPViewProps = { client: ApiClient; keyValue: string | null };

// GET /agents returns at most this many flows; a list that reaches it may be missing some.
const FLOW_CAP = 100;

/** MCP servers on the left, the selected one on the right: its tools, and a review of changed schemas. */
export function MCPView({ client, keyValue }: MCPViewProps) {
  const { serverId } = useParams();
  const navigate = useNavigate();
  const queryClient = useQueryClient();
  const [connecting, setConnecting] = useState(false);
  const [connectError, setConnectError] = useState<string | null>(null);

  const serversQuery = useQuery({ queryKey: ["mcp-servers"], queryFn: () => client.getMCPServers(), enabled: !!keyValue, retry: false });
  const flowsQuery = useQuery({ queryKey: ["agents"], queryFn: () => client.getAgents(), enabled: !!keyValue, retry: false });
  const servers = serversQuery.data ?? [];
  // The list endpoint has no tool counts, so each server's detail is read; the selected one reuses the same cache entry.
  const details = useQueries({
    queries: servers.map((s) => ({ queryKey: ["mcp-server", s.id], queryFn: () => client.getMCPServer(s.id), retry: false })),
  });

  const connect = useMutation({
    mutationFn: (input: CreateMCPServerInput) => client.createMCPServer(input),
    onSuccess: (created) => {
      setConnecting(false);
      setConnectError(null);
      void queryClient.invalidateQueries({ queryKey: ["mcp-servers"] });
      navigate(`/mcp-servers/${encodeURIComponent(created.id)}`);
    },
    onError: (err) => setConnectError(formatApiError(err, "Could not connect the server")),
  });

  const head = (
    <header className="page-head">
      <h1 tabIndex={-1}>MCP tools</h1>
      <span className="subtext">Remote servers whose tools flows can call mid-conversation.</span>
      <span className="grow" />
      {keyValue && (
        <button
          type="button"
          className="action-button"
          onClick={() => {
            setConnectError(null);
            setConnecting(true);
          }}
        >
          Connect server
        </button>
      )}
    </header>
  );
  const dialog = connecting && <ConnectServerDialog pending={connect.isPending} error={connectError} onSubmit={(input) => connect.mutate(input)} onCancel={() => setConnecting(false)} />;

  if (!keyValue) {
    return (
      <>
        {head}
        <EmptyState title="Connect to see MCP tools">Enter a management key above to see MCP servers and the tools they offer.</EmptyState>
      </>
    );
  }
  if (serversQuery.isPending) return <>{head}<LoadingState label="Loading MCP servers" /></>;
  if (serversQuery.isError) {
    return (
      <>
        {head}
        <ErrorState title="Could not load MCP servers" error={serversQuery.error as ApiError} onRetry={() => void serversQuery.refetch()} />
      </>
    );
  }
  if (servers.length === 0) {
    return (
      <>
        {head}
        <section className="message-panel">
          <h2>No MCP servers yet.</h2>
          <p>Connect a remote MCP server by its endpoint to let flows call its tools. Tokens are read only from MCP_TOKEN_* environment variables.</p>
        </section>
        {dialog}
      </>
    );
  }

  const flows = flowsQuery.data;
  const now = Date.now();
  const selectedIndex = serverId ? servers.findIndex((s) => s.id === serverId) : 0;
  const selected = selectedIndex >= 0 ? servers[selectedIndex] : undefined;
  const selectedDetail = selectedIndex >= 0 ? details[selectedIndex] : undefined;
  const toolCounts = Object.fromEntries(servers.map((s, i) => [s.id, details[i]?.data?.discovery?.tools.length ?? (details[i]?.isSuccess ? 0 : undefined)]));
  const changed = Object.fromEntries(servers.map((s) => [s.id, flows ? new Set(drifts(flows, s.id).filter((d) => d.kind === "changed").map((d) => d.dep.remote_name)).size : 0]));

  return (
    <>
      {head}
      <div className="mcp-layout">
        <nav aria-label="MCP servers" className="mcp-side">
          <ServerList servers={servers} toolCounts={toolCounts} changed={changed} selectedId={selected?.id} now={now} />
        </nav>
        <div className="mcp-main">
          {!selected ? (
            <section className="flow-missing">
              <p role="status">That MCP server was not found.</p>
              <Link to="/mcp-servers" className="action-button-small">
                Back to MCP tools
              </Link>
            </section>
          ) : selectedDetail?.isPending ? (
            <LoadingState label="Loading MCP server" />
          ) : selectedDetail?.isError || !selectedDetail?.data ? (
            <ErrorState title="Could not load the server" error={selectedDetail?.error as ApiError} onRetry={() => void selectedDetail?.refetch()} />
          ) : (
            <ServerDetail
              key={selected.id}
              client={client}
              server={selectedDetail.data}
              flows={flows}
              flowsCapped={(flows?.length ?? 0) >= FLOW_CAP}
              now={now}
              onDeleted={() => navigate("/mcp-servers")}
            />
          )}
        </div>
      </div>
      {dialog}
    </>
  );
}
```
