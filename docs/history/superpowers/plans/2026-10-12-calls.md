# Calls List and Call Detail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the "Sessions" table and trace page with the Switchboard **Calls** list (newest first, filterable by flow and live/ended, one lamp per live call) and a **call detail** page (who, which flow and version, the path through the steps, and a transcript labelled by step with the routes marked), keeping the raw trace one click away.

**Architecture:** Pure helpers (`callStats.ts`) turn what the API already returns (sessions, turns, handoff spans, the flow's current version) into labels: outcome, version, path, step-labelled transcript. `CallsView` reads `GET /sessions` with filters kept in the URL; `CallView` reads one session with its turns and traces and renders them through `CallTranscript`, with the existing `TurnTimeline` demoted into a "Technical trace" disclosure. No server or API change. The old `SessionsView` and `SessionDetailView` are deleted. Routes stay `/sessions` and `/sessions/:sessionId` (the code rename is spec S6).

**Tech Stack:** React 19, TypeScript 7, react-router 7, @tanstack/react-query 5, vitest 5 + Testing Library, Playwright (`e2e/tests-graph`).

**Spec:** `docs/superpowers/specs/2026-10-12-switchboard-console-design.md` (Sections 1, 3, 4, 5; this is "plan 3"). Visual rules: `docs/superpowers/specs/2026-10-12-ui-switchboard-design.md`. Canvas boards 13 (Calls) and 14 (Call detail).

## What the server really records (read before judging the canvas)

Verified in `server/` while writing this plan; it is why parts of boards 13–14 are left out:

- A session's `status` is `active`, `draining` or `ended`. Nothing ever writes `completed`, `failed` or `terminated`, although the old Sessions filter offered them (that filter could never match). The Outcome column therefore says **Live**, **Ending** or **Ended** only.
- Turn rows (`turns` table) hold the caller's words, the reply's words, `interrupted`, and the two timestamps. **`latencies_json` is never written** (always `{}`), so there is no per-turn VAD/STT/LLM/TTS breakdown to draw.
- Trace spans exist only for handoffs (`handoff.preparing | active | closed | failed`, attributes `from_node` and `to_node` as step ids, no `turn_id`) and MCP tool calls. A turn row does not say which step spoke; this plan derives it from the handoff times.
- The session row has no caller identity, no end reason, and no version number (only `agent_version_id`; a version's number is known only for the flow's *current* version).
- `GET /sessions` accepts `status`, `agent_id`, `limit` (1–100) and `offset`, orders by `started_at DESC`, and returns no total.

```ts
import type { AgentDTO, SessionDTO, SessionTracesDTO, TurnDTO } from "../../api/client";

/** The call's state in words. The server writes only active, draining and ended; anything else is shown as it is. */
export function outcome(s: SessionDTO): { label: string; live: boolean } {
  switch (s.status) {
    case "active":
      return { label: "Live", live: true };
    case "draining":
      return { label: "Ending", live: false };
    case "ended":
      return { label: "Ended", live: false };
    default:
      return { label: s.status, live: false };
  }
}

/** The API has no version list (spec S2): a version's number is known only while it is the flow's current one. */
export function versionLabel(s: SessionDTO, flow: AgentDTO | undefined): string {
  const current = flow?.current_version;
  return current && current.id === s.agent_version_id ? `v${current.number}` : "earlier version";
}

export function mmss(seconds: number): string {
  const total = Math.max(0, Math.round(seconds));
  const h = Math.floor(total / 3600);
  const m = String(Math.floor((total % 3600) / 60)).padStart(2, "0");
  const s = String(total % 60).padStart(2, "0");
  return h > 0 ? `${h}:${m}:${s}` : `${m}:${s}`;
}

/** Elapsed call time. `now` only matters while the call has not ended. */
export function clock(startedAt: string, endedAt: string | null | undefined, now: number): string {
  const end = endedAt ? Date.parse(endedAt) : now;
  return mmss((end - Date.parse(startedAt)) / 1000);
}

export type Steps = { names: Map<string, string>; entry: string | undefined };

/** Step names and the start step, from the flow's current version. Older calls may name steps that are gone. */
export function steps(flow: AgentDTO | undefined): Steps {
  const cfg = flow?.current_version?.config as { entry?: string; nodes?: { id: string; name?: string }[] } | undefined;
  const names = new Map<string, string>();
  for (const n of cfg?.nodes ?? []) names.set(n.id, n.name?.trim() || n.id);
  return { names, entry: cfg?.entry };
}

type Route = { at: number; from: string; to: string };

function spansNamed(traces: SessionTracesDTO | null | undefined, name: string): Route[] {
  return (traces?.spans ?? [])
    .filter((s) => s.name === name)
    .map((s) => {
      const a = (s.attributes ?? {}) as { from_node?: unknown; to_node?: unknown };
      return { at: Date.parse(s.started_at), from: String(a.from_node ?? ""), to: String(a.to_node ?? "") };
    })
    .filter((r) => r.to !== "")
    .sort((a, b) => a.at - b.at);
}

export function failedRoutes(traces: SessionTracesDTO | null | undefined): { from: string; to: string }[] {
  return spansNamed(traces, "handoff.failed").map(({ from, to }) => ({ from, to }));
}

export function path(traces: SessionTracesDTO | null | undefined, st: Steps, fallback: string): string[] {
  const label = (id: string) => st.names.get(id) ?? id;
  const routes = spansNamed(traces, "handoff.active");
  if (routes.length === 0) return [st.entry ? label(st.entry) : fallback];
  return [label(routes[0].from), ...routes.map((r) => label(r.to))];
}

export type CallLine =
  | { kind: "say"; who: "caller" | "step"; label: string; at: string; text: string; interrupted: boolean }
  | { kind: "route"; at: string; from: string; to: string };

/**
 * The words of a call, in order, each reply labelled with the step that was active when it was said.
 * A turn row does not name its step, so this uses the times of the route (handoff) spans.
 */
export function transcript(session: SessionDTO, turns: TurnDTO[], traces: SessionTracesDTO | null | undefined, st: Steps, fallback: string): CallLine[] {
  const start = Date.parse(session.started_at);
  const at = (t: number) => mmss((t - start) / 1000);
  const label = (id: string) => st.names.get(id) ?? id;
  const routes = spansNamed(traces, "handoff.active");
  const activeAt = (t: number) => {
    let id = routes.length > 0 ? routes[0].from : (st.entry ?? "");
    for (const r of routes) if (r.at <= t) id = r.to;
    return id ? label(id) : fallback;
  };

  const out: CallLine[] = [];
  let next = 0;
  const flush = (until: number) => {
    while (next < routes.length && routes[next].at <= until) {
      const r = routes[next++];
      out.push({ kind: "route", at: at(r.at), from: label(r.from), to: label(r.to) });
    }
  };

  const ordered = [...turns].sort((a, b) => a.ordinal - b.ordinal || Date.parse(a.started_at) - Date.parse(b.started_at));
  for (const t of ordered) {
    const said = t.transcript.trim();
    const reply = t.assistant_text.trim();
    const began = Date.parse(t.started_at);
    const ended = t.ended_at ? Date.parse(t.ended_at) : began;
    if (said) {
      flush(began);
      out.push({ kind: "say", who: "caller", label: "Caller", at: at(began), text: said, interrupted: false });
    }
    if (reply) {
      flush(ended);
      out.push({ kind: "say", who: "step", label: activeAt(ended), at: at(ended), text: reply, interrupted: t.interrupted });
    }
  }
  flush(Infinity);
  return out;
}

export function interruptedCount(turns: TurnDTO[]): number {
  return turns.filter((t) => t.interrupted).length;
}
```

```tsx
import { useState } from "react";
import { Link, useSearchParams } from "react-router";
import { useQuery } from "@tanstack/react-query";
import type { AgentDTO, ApiClient, ApiError } from "../../api/client";
import { DataTable, EmptyState, ErrorState, LoadingState } from "../../components/primitives";
import { useActiveSessions } from "../agents/useActiveSessions";
import { clock, outcome, versionLabel } from "./callStats";

export type CallsViewProps = { client: ApiClient; keyValue: string | null };

const PAGE = 25;
const LIVE_CAP = 100;
type OutcomeFilter = "" | "live" | "ended";
const OUTCOMES: { id: OutcomeFilter; label: string }[] = [
  { id: "", label: "All" },
  { id: "live", label: "Live" },
  { id: "ended", label: "Ended" },
];

/** Every call, newest first. Filters live in the URL so a link (from the Flows list) can open one. */
export function CallsView({ client, keyValue }: CallsViewProps) {
  const [params, setParams] = useSearchParams();
  const [page, setPage] = useState(0);
  const flowId = params.get("flow") ?? "";
  const raw = params.get("outcome");
  const outcomeId: OutcomeFilter = raw === "live" || raw === "ended" ? raw : "";
  const status = outcomeId === "live" ? "active" : outcomeId === "ended" ? "ended" : undefined;

  // One extra row tells us whether an older page exists; the API returns no total.
  const calls = useQuery({
    queryKey: ["sessions", "list", flowId, outcomeId, page],
    queryFn: () => client.getSessions({ limit: PAGE + 1, offset: page * PAGE, status, agent_id: flowId || undefined }),
    enabled: !!keyValue,
    retry: false,
    refetchInterval: 10_000,
  });
  const flowsQuery = useQuery({ queryKey: ["agents"], queryFn: () => client.getAgents(), enabled: !!keyValue, retry: false });
  const active = useActiveSessions(client, keyValue);

  const setFilter = (next: { flow?: string; outcome?: OutcomeFilter }) => {
    const flow = next.flow ?? flowId;
    const out = next.outcome ?? outcomeId;
    const p = new URLSearchParams();
    if (flow) p.set("flow", flow);
    if (out) p.set("outcome", out);
    setParams(p, { replace: true });
    setPage(0);
  };

  const heading = (
    <header className="section-heading">
      <h1 tabIndex={-1}>Calls</h1>
      <p>Every call, newest first. Open one to read what was said and see where it moved.</p>
    </header>
  );
  if (!keyValue) {
    return (
      <>
        {heading}
        <EmptyState title="Connect to see calls">Enter a management key above to see calls.</EmptyState>
      </>
    );
  }

  const flows = new Map<string, AgentDTO>((flowsQuery.data ?? []).map((f) => [f.id, f]));
  const liveNow = active.data?.length;
  const liveText = liveNow === undefined ? "" : liveNow >= LIVE_CAP ? `${LIVE_CAP}+` : String(liveNow);
  const rows = (calls.data ?? []).slice(0, PAGE);
  const hasOlder = (calls.data?.length ?? 0) > PAGE;
  const filtered = flowId !== "" || outcomeId !== "";
  const now = Date.now();

  return (
    <>
      {heading}
      <div className="calls-toolbar">
        <p className="subtext" role="status">
          {liveNow === undefined ? "Most recent first" : `${liveText} live now`}
        </p>
        <span className="grow" />
        <label className="form-field calls-flow" htmlFor="calls-flow">
          <span>Flow</span>
          <select id="calls-flow" value={flowId} onChange={(e) => setFilter({ flow: e.target.value })}>
            <option value="">All flows</option>
            {flowId !== "" && !flows.has(flowId) && <option value={flowId}>Unknown flow</option>}
            {[...flows.values()].map((f) => (
              <option key={f.id} value={f.id}>
                {f.name}
                {f.archived ? " (archived)" : ""}
              </option>
            ))}
          </select>
        </label>
      </div>
      <div role="group" aria-label="Outcome" className="calls-chips">
        {OUTCOMES.map((o) => (
          <button key={o.id} type="button" className="chip-button" aria-pressed={outcomeId === o.id} onClick={() => setFilter({ outcome: o.id })}>
            {o.id === "live" && liveNow !== undefined ? `Live · ${liveText}` : o.label}
          </button>
        ))}
      </div>

      {calls.isPending ? (
        <LoadingState label="Loading calls" />
      ) : calls.isError ? (
        <ErrorState title="Could not load calls" error={calls.error as ApiError} onRetry={() => void calls.refetch()} />
      ) : rows.length === 0 ? (
        filtered ? (
          <section className="message-panel">
            <h2>No calls match these filters.</h2>
            <p>
              <button type="button" className="action-button-small" onClick={() => setFilter({ flow: "", outcome: "" })}>
                Clear filters
              </button>
            </p>
          </section>
        ) : (
          <section className="message-panel">
            <h2>No calls yet.</h2>
            <p>Calls appear here as soon as someone talks to a flow. Test one from the editor to see how this looks.</p>
            <p>
              <Link to="/flows" className="action-button-small">
                Go to Flows
              </Link>
            </p>
          </section>
        )
      ) : (
        <>
          <DataTable
            caption="Calls, newest first"
            columns={["Started", "Flow", "Duration", "Turns", "Outcome"]}
            rows={rows.map((s) => {
              const o = outcome(s);
              const f = flows.get(s.agent_id);
              return [
                <Link key="started" to={`/sessions/${encodeURIComponent(s.id)}`}>
                  {new Date(s.started_at).toLocaleString()}
                </Link>,
                <span key="flow">
                  {f?.name ?? "Unknown flow"} <span className="chip">{versionLabel(s, f)}</span>
                </span>,
                clock(s.started_at, s.ended_at, now),
                s.turn_count,
                <span key="outcome" className="row">
                  <span className="lamp" data-tone={o.live ? "warn" : undefined} aria-hidden="true" />
                  {o.label}
                </span>,
              ];
            })}
          />
          <nav className="calls-pager" aria-label="Pagination">
            <span>
              Calls {page * PAGE + 1}–{page * PAGE + rows.length}
            </span>
            <span className="grow" />
            <button type="button" className="action-button-small" disabled={page === 0} onClick={() => setPage(page - 1)}>
              Newer
            </button>
            <button type="button" className="action-button-small" disabled={!hasOlder} onClick={() => setPage(page + 1)}>
              Older
            </button>
          </nav>
        </>
      )}
    </>
  );
}
```

```tsx
import { useQuery } from "@tanstack/react-query";
import { Link, useParams } from "react-router";
import type { ApiClient, ApiError } from "../../api/client";
import { EmptyState, ErrorState, LoadingState } from "../../components/primitives";
import { TurnTimeline } from "../../components/timeline/TurnTimeline";
import { CallTranscript } from "./CallTranscript";
import { clock, failedRoutes, interruptedCount, outcome, path, steps, transcript, versionLabel } from "./callStats";

export type CallViewProps = { client: ApiClient; keyValue: string | null };

const LIVE_POLL_MS = 5_000;

/** One call: the figures, the path through the steps, the transcript, and the raw trace one click away. */
export function CallView({ client, keyValue }: CallViewProps) {
  const { sessionId = "" } = useParams();
  const on = !!keyValue && !!sessionId;
  const sessionQuery = useQuery({
    queryKey: ["session", sessionId],
    queryFn: () => client.getSession(sessionId),
    enabled: on,
    retry: false,
    refetchInterval: (q) => (q.state.data?.status === "active" ? LIVE_POLL_MS : false),
  });
  const running = sessionQuery.data?.status === "active";
  const turnsQuery = useQuery({
    queryKey: ["session-turns", sessionId],
    queryFn: () => client.getSessionTurns(sessionId),
    enabled: on,
    retry: false,
    refetchInterval: running ? LIVE_POLL_MS : false,
  });
  const tracesQuery = useQuery({
    queryKey: ["session-traces", sessionId],
    queryFn: () => client.getSessionTraces(sessionId),
    enabled: on,
    retry: false,
    refetchInterval: running ? LIVE_POLL_MS : false,
  });
  const flowsQuery = useQuery({ queryKey: ["agents"], queryFn: () => client.getAgents(), enabled: on, retry: false });

  if (!keyValue) return <EmptyState title="Connect to see this call">Enter a management key above to see this call.</EmptyState>;
  if (sessionQuery.isPending) return <LoadingState label="Loading call" />;
  if (sessionQuery.isError) {
    const err = sessionQuery.error as ApiError;
    if (err.status === 404) {
      return (
        <section className="flow-missing">
          <p role="status">That call was not found.</p>
          <Link to="/sessions" className="action-button-small">
            Back to calls
          </Link>
        </section>
      );
    }
    return <ErrorState title="Could not load the call" error={err} onRetry={() => void sessionQuery.refetch()} />;
  }

  const s = sessionQuery.data;
  const flow = (flowsQuery.data ?? []).find((f) => f.id === s.agent_id);
  const fallback = flow?.name ?? "Assistant";
  const st = steps(flow);
  const turns = turnsQuery.data ?? [];
  const traces = tracesQuery.data ?? null;
  const o = outcome(s);
  const label = (id: string) => st.names.get(id) ?? id;
  const failed = failedRoutes(traces);

  return (
    <div className="call-page">
      <nav aria-label="Breadcrumb" className="flow-page__crumb">
        <Link to="/sessions">Calls</Link>
      </nav>
      <header className="call-head">
        <h1 tabIndex={-1}>Call {s.id.slice(0, 8)}</h1>
        <span className="call-state">
          <span className="lamp" data-tone={o.live ? "warn" : undefined} aria-hidden="true" />
          {o.label} · {clock(s.started_at, s.ended_at, Date.now())}
        </span>
      </header>

      <dl className="call-figures">
        <div>
          <dt>Flow</dt>
          <dd>
            {flow && !flow.archived ? <Link to={`/flows/${encodeURIComponent(flow.id)}`}>{flow.name}</Link> : <span>{flow ? `${flow.name} (archived)` : "Unknown flow"}</span>}{" "}
            <span className="chip">{versionLabel(s, flow)}</span>
          </dd>
        </div>
        <div>
          <dt>Started</dt>
          <dd>{new Date(s.started_at).toLocaleString()}</dd>
        </div>
        <div>
          <dt>Duration</dt>
          <dd>{clock(s.started_at, s.ended_at, Date.now())}</dd>
        </div>
        <div>
          <dt>Turns</dt>
          <dd>{s.turn_count}</dd>
        </div>
        <div>
          <dt>Interrupted replies</dt>
          <dd>{interruptedCount(turns)}</dd>
        </div>
        <div>
          <dt>Path</dt>
          <dd>{path(traces, st, fallback).join(" → ")}</dd>
        </div>
      </dl>

      {failed.map((f, i) => (
        <p key={i} role="note" className="call-note">
          A route to {label(f.to)} failed. The caller stayed with {label(f.from)}.
        </p>
      ))}
      {tracesQuery.isError && <p role="note" className="call-note">Steps and routes could not be loaded, so the transcript is not labelled by step.</p>}

      <section aria-labelledby="call-transcript-title" className="call-section">
        <h2 id="call-transcript-title">Transcript</h2>
        {turnsQuery.isError ? (
          <ErrorState title="Could not load the transcript" error={turnsQuery.error as ApiError} onRetry={() => void turnsQuery.refetch()} />
        ) : turnsQuery.isPending ? (
          <LoadingState label="Loading transcript" />
        ) : (
          <CallTranscript lines={transcript(s, turns, traces, st, fallback)} />
        )}
      </section>

      <details className="call-technical">
        <summary>Technical trace</summary>
        <dl className="call-figures">
          <div>
            <dt>Call id</dt>
            <dd>
              <code>{s.id}</code>
            </dd>
          </div>
          <div>
            <dt>Config hash</dt>
            <dd>
              <code>{s.config_hash || "none"}</code>
            </dd>
          </div>
          {s.safe_summary && (
            <div>
              <dt>Summary</dt>
              <dd>{s.safe_summary}</dd>
            </div>
          )}
        </dl>
        {s.runtime_tools && s.runtime_tools.length > 0 && (
          <section aria-label="Tools captured for this call">
            <h3>Tools captured for this call ({s.runtime_tools.length})</h3>
            <ul className="call-tools">
              {s.runtime_tools.map((t) => (
                <li key={`${t.mcp_server_id}/${t.remote_name}`}>
                  <strong>{t.remote_name}</strong> <span className="subtext">on {t.mcp_server_id}</span> <code>{t.schema_hash.slice(0, 8)}</code> {t.required ? "Required" : "Optional"}
                </li>
              ))}
            </ul>
          </section>
        )}
        <TurnTimeline turns={turns} traces={traces} loading={turnsQuery.isPending} />
      </details>
    </div>
  );
}
```
