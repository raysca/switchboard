## Rulings (mine; recorded in the ledger; the reviewer may challenge them)

- **R1 Frame numbers stay stable.** `core/frame.go:20-62` numbers frame types with `X + iota` where `iota` is the index in the whole const block, so deleting a constant shifts every later value (e.g. `FrameEnd` is 718 today). Values reach traces (`frameTraceLabel` default `strconv.Itoa`, `core/session.go:1143`) and Whisker events (`frame_kind`). Each deleted constant is replaced by `_ // FrameX, deleted in Phase 5`; Task 5.0 adds a test that pins every remaining value first.
- **R2 D-0.2 resolves to "frame path" (measured).** D-0.2: frame path, unless it is more than ~60 lines. A prototype in a scratch clone (`git clone --local`, 2026-10-18) added **+28 / −16 non-test lines** (3 files; tests +3/−3) and passed `go test -race -count=3 ./core/audio/dtmf/` and the server DTMF tests. An earlier draft of this plan ruled "delete the frame" on an unmeasured estimate; that is withdrawn. A barge-in fence is handled without new drop detection: the tool loop's stale watch cancels the call's ctx (`core/tools/parallel.go:45-48,118`), which ends the executor's wait. Task 5.1c.
- **R3 D-0.1 applied.** Whisker stays in `tools/compat/whisker` with its runner `tools/eval/eval.go`. Its seven envelope fields leave `core.DebugEvent` (`core/debug.go:13-19`) for a whisker-local struct; `StartFrame`/`CancelFrame`/`TTSAudioFrame` become whisker-local frame types. No build tag is needed: the code is already outside `core/`. `Session.DebugDropped` is deleted.
- **R4 `TurnEventNoSpeechTimeout` is deleted although it is reachable.** `server/registry.go:724` uses `coreturn.DefaultConfig()` (`InitialSilenceTimeout` 10 s), so the manager can emit it, but only on a processor tick after 10 s with no accepted speech (`core/turn/processor.go:181-183`: "the manager's initial no-speech event is trace-only"). Its effects: a `turn.complete` trace event and an idle-clock re-arm (`core/idle.go:290`) that can only delay a prompt. The re-arm is **unpinned and near-unreachable**: no test covers it; the idle e2e (`server/call_behavior_e2e_test.go:57-90`) covers prompts in general, and Phase 7.5 adds `idle.user_timeout`. Removing `TurnReasonInitialNoSpeech` shifts `TurnReasonInterrupted` from 5 to 4; reasons are not persisted or sent as numbers, so this is harmless.
- **R5 Tests that exercise a dead symbol only are deleted with it; tests that pin real behaviour are rewritten** to the production path. Concretely: `Manager.Interrupt` (only caller `tools/compat/pipecat_parity_test.go:49`) goes, and the parity test reaches the same interruption through the production path (an observation with a newer generation, `core/turn/manager.go:232-234`), keeping `fixtures/pipecat-turn-parity.json` unchanged.
- **R6 Keep, with reason:** `core.SplitNext` (`core/sentence_export.go:6`; only `tools/ttssim` (`make tts-sim`) uses it, and it exposes the production segmenter; a copy would drift); `netpool.Requests` (`core/netpool/netpool.go:168`; `tools/provtest/suite.go:108,121,226`, run by `make provider-matrix-dry`); `IdleController.SpeakIndex` (`core/idle.go:178`; `server/idle_test.go:379-386` pins that the server wires the TTS index); `turn.AnalyzerResult` (used by `smartturn`); `TurnReasonSemantic` (returned by `smartturn.Stop`, `smartturn/analyzer.go:294`); `Denoiser.Delay` (pins measured latency in `denoise_test.go:191`); `ToolCallFrame`/`ToolResultFrame` (wired in Phase 3); `ValidateToolPairing` moves to `core/coretest` (a test oracle used by `core/tools/pairing_test.go:23` and `providers/google/tool_adapter_test.go:186`); `STTFailover.Buffered` (bound test `core/stt_failover_test.go:310`, package `core_test`: unexporting needs an `export_test.go` shim, more code than the getter); `ConversationContext.EstimatedTokens` (read by `server/summarize_test.go:154,183,213` from package `server`); `OutputDTMFFrame` (wired, 5.1c).
- **R8 Unread trace labels go.** `turn_label` on MCP spans (`server/trace/adapter.go:100-102`) is read by nothing (no UI, no docs); mapping core turn ids to stored turn rows would be a feature, not a cleanup.
- **R9 An always-zero metric is removed.** `voice_stt_deduplicated_results_total` is never incremented anywhere (`DeduplicatedResults`); a metric that is always 0 misleads operators. Release-note it.
- **R7 deadcode roots.** The master's command roots only `./cmd/... ./examples/...`; tools are real programs (Makefile targets `tts-sim`, `provider-matrix*`, `eval-turn`, `bench-latency`, `loadtest-*`, `live-*`). The gate runs both: the master command (29 lines today) **and** the wide one with `./tools/... ./offline/cmd/...` (40 lines). Phase gate: after ⊂ before for both.
